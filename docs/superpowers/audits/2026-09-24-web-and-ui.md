# Audit: `apps/web`, `packages/ui`, legacy `apps/alxnko-dev` (brand v2, B7)

Date: 2026-09-24 · Branch audited: `docs/brand-v2` (same `apps/web` / `packages/ui` source as `master` except
where noted) · Mode: read-only (no code changed, nothing committed, no forms submitted, no sign-in).
Decisions: `docs/superpowers/decisions/2026-09-24-brand-v2-log.md` (B1–B10). Spec:
`docs/superpowers/specs/2026-09-24-brand-v2-design.md`.

Artifacts (screenshots, Lighthouse JSON, contrast tables, coverage, build copy):
`/var/tmp/brand-v2-audit/web-ui/`.

- `live-{phone,desktop}-{light,dark}.png`, `live404-*.png`, `local-*.png`, `local-api-{abort,hang}.png`
- `lh-{live,local}-{mobile,desktop}.json`
- `contrast-current.txt` (every current `packages/ui` token pair), `contrast-target.txt` (alxnko.dev tokens + ANSI)

Severity: **Critical** (broken or unsafe in production) · **High** (real user harm, a11y failure, or a

## Summary

| | Critical | High | Medium | Low | Total |
|---|---|---|---|---|---|
| W (apps/web) | 1 | 4 | 10 | 4 | 19 |
| U (packages/ui) | 0 | 7 | 16 | 8 | 31 |

| **Total** | **1** | **12** | **28** | **15** | **56** |

Top 5:
1. **W-01**: meow.alxnko.dev is an unstyled demo whose only action ("add") can never succeed. The
   write token is empty, so every POST gets a 401 and fails silently. This is the textbook B9 case.
2. **U-01/U-02**: `useSession` treats every failure (network, 5xx, bad JSON) as "signed out" and
   has no timeout. `AuthGate` therefore either spins forever or sends a signed-in user to `/login`.
3. **U-06/U-07**: the `Modal` focus trap leaks when the last button is disabled, which is the
   `ConfirmDialog` type-to-confirm case. The trap also re-runs on every parent render, which pulls
   focus out of the field being typed in. That happens in auth-web and meowsenger.
4. **U-31**: `ConfirmDialog` compares the phrase case-sensitively, but the global lowercase CSS
   shows the label in lowercase. A phrase with capitals (a username) can't be matched by typing
   what's on screen. The confirm button stays disabled and nothing says why.
5. **L-01**: `infra/cloudflare/deploy-alxnko-dev.sh` still deploys the legacy app to the same
   Pages project (`alxnko-dev`) that now serves the live desk site from the separate repo. One run
   would overwrite production alxnko.dev with the old site.

Legacy verdict: `apps/alxnko-dev` is **not deployed anywhere now**. The last 7 production
deployments of Pages project `alxnko-dev` all come from the separate `alxnko.dev` repo, newest
`b1808d5`. The 6 before them (4 days old) were built from this monorepo. The app is still wired
into the workspace, CI lint, the brand icon script and a live-capable deploy script. It is safe to
retire with the checklist below.

### 5c. Token gaps that stop tty and app elements sharing geometry

| Gap | Why it blocks cohesion | Proposal |
|---|---|---|
| G-1 `--control-h` / `--control-h-sm` | Field and Button use 42/34 literals; the tty chip uses 30; the spec needs 44 targets | `--control-h: 44px`; `--control-h-sm: 32px` visual + 44 hit box |
| G-2 `--control-px`, `--control-py` | Four different paddings today (10×13, 10×18, 7×13, 9×11) | one pair shared by Field, Prompt and Button |
| G-3 `--line-w` + `--c-line-input` | 0.5px vs 1px; `--c-line-strong` is under 3:1, so a Prompt frame and a Field frame can't both be accessible with the same token | `--line-w: 1px`; `--c-line-input: var(--c-fg-subtle)` (≥5.3:1) |
| G-4 `--lh-body` | 1.6 (ui and alxnko.dev body) vs 1.55 (terminal) vs 1.5 (spec §2.2); a StatusLine must match body line height (B10.3) | one `--lh-body`, used by StatusLine and body |
| G-5 theme-aware status tokens `--c-ok`, `--c-warn`, `--c-danger`, `--c-info` | ANSI colours fail on light surfaces (green 1.1:1), so StatusLine can't use `--ansi-*` in light pages (B10.1 forbids black-box panels) | StatusLine glyphs use `--c-ok` (= `--c-accent`), `--c-warn`, `--c-danger`, `--c-info`; ANSI stays inside `--ansi-bg` code blocks only |
| G-6 `--opacity-disabled` + a disabled-reason pattern | Button .55, Checkbox .55, Field none, Prompt undefined (B10.4) | one token plus a `data-reason` / `aria-describedby` helper |
| G-7 focus: one ring token set (`--c-focus`, `--focus-w: 2px`, `--focus-offset: 2px`) | ui uses a box-shadow ring; the alxnko.dev terminal input uses none | one outline rule for every control, including Prompt |
| G-8 `--fs-input` | Prompt and Field must be 16px on phones (iOS zoom) while body is 14 | `--fs-input: max(16px, var(--fs-3))` under a coarse pointer |
| G-9 `--prompt-glyph-gap` (1ch) and cursor tokens (`--cursor-w`, `--cursor-blink: 1s steps(1)`) | Needed so `›` and the cursor sit on the same metrics as the text (B10.2) | new tokens, JBM-only so `ch` is exact |
| G-10 `--r-pill` decision | Avatar circle and Badge pill vs the tty 2–4px radii | keep a pill only for Avatar and Switch; badges become `--r-s` |
| G-11 `--shadow-sheet`, `--c-scrim`, `--z-toast` | Modal, Toast and Drawer need elevation the flat alxnko.dev system lacks | add these three and nothing more |
| G-12 fallback font face | Without a metric-matched `JetBrains Mono Fallback`, prompts and buttons shift on font swap | copy from alxnko.dev `base.css` |
